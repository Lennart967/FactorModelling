# FactorModelling
This repo will explain what factor models are, how to use them and will even provide some examples on how you can use factor modelling to determine your risk-exposure to different market sectors.

**1. First, start with CAPM, it's the most basic of all factor models and will give you a great introduction to start off**

**2. To continue, look at FAMA French and understand how to add more factors and also, how to decompose a fund into different risk sectors**
